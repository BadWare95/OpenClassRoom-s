Cours suivi

Concepts clés

Partie 1 - Découvrez le web et ses origines

Web

Ensemble des pages accessibles sur Internet.

Internet

Réseau mondial de serveurs interconnectés.

Cloud

Stockage et traitement des données sur des serveurs distants.

W3C

Organisation qui définit les standards du web.

Partie 2 - Distinguez les langages du Web

Langages client

Langages exécutés sur le navigateur de l'utilisateur (ex: HTML, CSS, JavaScript).

Navigateurs

Logiciels permettant d'accéder et d'afficher des pages web.

Langages serveur

Langages exécutés sur le serveur (ex: PHP, Python, Ruby).

Frameworks

Ensemble d'outils et de bibliothèques facilitant le développement d'applications web.

Bases de données

Systèmes permettant de stocker et de gérer des données (ex: MySQL, MongoDB).

Site responsive

Site web s'adaptant à toutes les tailles d'écran (mobiles, tablettes, ordinateurs).

Application mobile

Application conçue pour être utilisée sur des appareils mobiles (smartphones, tablettes).

Partie 3 - Découvrez le fonctionnement du réseau

Serveurs

Machines hébergeant des applications et des données, accessibles via le réseau.

Adresse IP

Identifiant unique attribué à chaque appareil sur un réseau.

Nom d’hôte et DNS

Nom d'un serveur sur le réseau et système de résolution de noms.

Protocoles

Ensemble de règles régissant les échanges de données sur un réseau.

Partie 4 - Identifiez les métiers du web

Développeurs

Professionnels créant et maintenant des applications web.

Product Managers et chefs de projets

Responsables de la planification et de la gestion des projets de développement.

Designers

Professionnels créant l'interface et l'expérience utilisateur des applications web.

Testeurs

Professionnels vérifiant la qualité et le bon fonctionnement des applications web.

Techniciens informatique

Professionnels assurant le support technique et la maintenance des systèmes informatiques.

Langages de développement web

HTML

Front-End

Squelette du site Web. Il définit la structure de base du contenu, comme les titres, les paragraphes, les images, etc.

CSS

Front-End

Langage de style utilisé pour décrire la présentation des documents HTML.

JavaScript

Front-End

Langage de programmation permettant d'ajouter de l'interactivité aux pages web.

JavaScript

Back-End

Langage de programmation utilisé pour créer des applications web côté serveur.

PHP

Back-End

Langage de script côté serveur utilisé pour développer des applications web dynamiques.

Java

Back-End

Langage de programmation orienté objet utilisé pour développer des applications web et mobiles.

Python

Back-End

Langage de programmation polyvalent utilisé pour le développement web, l'analyse de données et l'intelligence artificielle.

C#

Back-End

Langage de programmation orienté objet utilisé pour développer des applications web et mobiles.

SQL

Bases de données

Langage de requête utilisé pour interagir avec des bases de données relationnelles.

Boîte à outils du développeur

  • IDE comme VS Code : Environnement de développement intégré utilisé pour écrire et tester du code.
  • Github : Plateforme de gestion de versions et de collaboration pour le code source.
  • Librairies / bibliothèques : Ensembles de fonctions et de ressources réutilisables pour faciliter le développement.
  • Frameworks : Structures de développement qui facilitent la création d'applications. Exemples : Django (Python), React (JavaScript), .NET (C#).
